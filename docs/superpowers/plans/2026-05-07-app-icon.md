# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the suppressed MissingApplicationIcon with a real adaptive launcher icon (shield + eye on green).

**Architecture:** Android adaptive icon (API 26+) using vector drawables for foreground/background layers, with PNG fallbacks for older devices. The icon.svg source is rendered to PNGs at all required densities via rsvg-convert.

**Tech Stack:** Android VectorDrawable XML, SVG, rsvg-convert / ImageMagick for PNG rendering.

### Task 1: Create ic_launcher_background.xml

**Files:**
- Create: `app/src/main/res/drawable/ic_launcher_background.xml`

- [ ] **Step 1.1: Write the background drawable**

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <color name="ic_launcher_background">#4CAF50</color>
</resources>
```

Wait — background drawable must be a `<color>` or `<shape>`. For adaptive icons the background is typically a color resource or a simple drawable. The standard approach:

```xml
<?xml version="1.0" encoding="utf-8"?>
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="108dp"
    android:height="108dp"
    android:viewportWidth="108"
    android:viewportHeight="108">
    <path
        android:fillColor="#4CAF50"
        android:pathData="M0,0h108v108h-108z" />
</vector>
```

Or simpler — a `<color>` drawable:

```xml
<?xml version="1.0" encoding="utf-8"?>
<color xmlns:android="http://schemas.android.com/apk/res/android"
    android:color="#4CAF50" />
```

Use the color drawable — it's simpler and functionally identical.

- [ ] **Step 1.2: Create the drawable directory if needed**

```bash
mkdir -p app/src/main/res/drawable
```

- [ ] **Step 1.3: Commit**

```bash
git add app/src/main/res/drawable/ic_launcher_background.xml
git commit -m "feat: add icon background drawable (green #4CAF50)"
```

### Task 4: Generate PNG fallback icons

**Files:**
- Create: `app/src/main/res/mipmap-mdpi/ic_launcher.png`
- Create: `app/src/main/res/mipmap-hdpi/ic_launcher.png`
- Create: `app/src/main/res/mipmap-xhdpi/ic_launcher.png`
- Create: `app/src/main/res/mipmap-xxhdpi/ic_launcher.png`
- Create: `app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`

- [ ] **Step 4.1: Write the source SVG**

Create an SVG version of the icon that matches the vector drawable, used for rendering PNGs:

```xml
<?xml version="1.0" encoding="utf-8"?>
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 108 108" width="108" height="108">
  <!-- Background circle (safe zone indicator, will be clipped to bg) -->
  <rect width="108" height="108" fill="#4CAF50"/>
  <!-- Shield -->
  <path d="M54 18 L28 30 L28 52 C28 70 39 83 54 90 C69 83 80 70 80 52 L80 30 Z" fill="white"/>
  <!-- Eye ellipse -->
  <ellipse cx="54" cy="57" rx="12" ry="8" fill="#4CAF50"/>
  <!-- Iris -->
  <circle cx="54" cy="57" r="4" fill="white"/>
  <!-- Upper eyelid -->
  <path d="M42 57 C46 49 62 49 66 57" stroke="#4CAF50" stroke-width="2.5" fill="none" stroke-linecap="round"/>
  <!-- Lower eyelid -->
  <path d="M42 57 C46 65 62 65 66 57" stroke="#4CAF50" stroke-width="2.5" fill="none" stroke-linecap="round"/>
</svg>
```

Save this to `/tmp/ezworksafe-icon.svg`.

- [ ] **Step 4.2: Render PNGs at all densities**

```bash
mkdir -p app/src/main/res/mipmap-mdpi
mkdir -p app/src/main/res/mipmap-hdpi
mkdir -p app/src/main/res/mipmap-xhdpi
mkdir -p app/src/main/res/mipmap-xxhdpi
mkdir -p app/src/main/res/mipmap-xxxhdpi

rsvg-convert -w 48 -h 48 /tmp/ezworksafe-icon.svg -o app/src/main/res/mipmap-mdpi/ic_launcher.png
rsvg-convert -w 72 -h 72 /tmp/ezworksafe-icon.svg -o app/src/main/res/mipmap-hdpi/ic_launcher.png
rsvg-convert -w 96 -h 96 /tmp/ezworksafe-icon.svg -o app/src/main/res/mipmap-xhdpi/ic_launcher.png
rsvg-convert -w 144 -h 144 /tmp/ezworksafe-icon.svg -o app/src/main/res/mipmap-xxhdpi/ic_launcher.png
rsvg-convert -w 192 -h 192 /tmp/ezworksafe-icon.svg -o app/src/main/res/mipmap-xxxhdpi/ic_launcher.png
```

- [ ] **Step 4.3: Commit**

```bash
git add app/src/main/res/mipmap-*/ic_launcher.png
git commit -m "feat: add PNG fallback icons for all densities"
```
