# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Material You dynamic color dark mode support to the Compose UI.

**Architecture:** New `EzWorkSafeTheme` composable wrapping `MaterialTheme` with dynamic colors on API 31+ and seeded fallback on older devices. The UI then references `MaterialTheme.colorScheme` instead of hardcoded colors.

**Tech Stack:** Jetpack Compose Material3, `dynamicLightColorScheme`/`dynamicDarkColorScheme`, `isSystemInDarkTheme`.

### Task 1: Create EzWorkSafeTheme.kt

**Files:**
- Create: `app/src/main/java/com/ezworksafe/ui/view/EzWorkSafeTheme.kt`

- [ ] **Step 1.1: Write EzWorkSafeTheme.kt**

```kotlin
package com.ezworksafe.ui.view

import android.os.Build
import androidx.compose.foundation.isSystemInDarkTheme
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.darkColorScheme
import androidx.compose.material3.dynamicDarkColorScheme
import androidx.compose.material3.dynamicLightColorScheme
import androidx.compose.material3.lightColorScheme
import androidx.compose.runtime.Composable
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.platform.LocalContext

private val LightColorScheme = lightColorScheme(
    primary = Color(0xFF4CAF50),
)

private val DarkColorScheme = darkColorScheme(
    primary = Color(0xFF4CAF50),
)

@Composable
fun EzWorkSafeTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    val colorScheme = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
        val context = LocalContext.current
        if (darkTheme) dynamicDarkColorScheme(context) else dynamicLightColorScheme(context)
    } else {
        if (darkTheme) DarkColorScheme else LightColorScheme
    }

    MaterialTheme(
        colorScheme = colorScheme,
        content = content
    )
}
```

### Task 2: Update StatusDashboard.kt to use theme colors

**Files:**
- Modify: `app/src/main/java/com/ezworksafe/ui/view/StatusDashboard.kt`

- [ ] **Step 2.1: Replace hardcoded colors with MaterialTheme.colorScheme**

Changes:
- `Color(0xFFF5F5F5)` → `MaterialTheme.colorScheme.background`
- `Color.White` (card) → `MaterialTheme.colorScheme.surface`
- `Color.Gray` (subtitle) → `MaterialTheme.colorScheme.onSurfaceVariant`
- Keep signal colors `Color(status.color.toInt())` as-is

Current code:
```kotlin
import androidx.compose.material3.MaterialTheme
// ...
    Column(
        modifier = Modifier
            .fillMaxSize()
            .background(Color(0xFFF5F5F5))
// ...
    Text(
        text = "Sensor Status",
        fontSize = 16.sp,
        color = Color.Gray,
// ...
    Card(
        modifier = Modifier.fillMaxWidth(),
        shape = RoundedCornerShape(12.dp),
        colors = CardDefaults.cardColors(containerColor = Color.White),
```

After:
```kotlin
import androidx.compose.material3.MaterialTheme
// ...
    Column(
        modifier = Modifier
            .fillMaxSize()
            .background(MaterialTheme.colorScheme.background)
// ...
    Text(
        text = "Sensor Status",
        fontSize = 16.sp,
        color = MaterialTheme.colorScheme.onSurfaceVariant,
// ...
    Card(
        modifier = Modifier.fillMaxWidth(),
        shape = RoundedCornerShape(12.dp),
        colors = CardDefaults.cardColors(containerColor = MaterialTheme.colorScheme.surface),
```

Also add `import androidx.compose.material3.MaterialTheme` if not already present.

### Task 4: Update XML theme to DayNight

**Files:**
- Modify: `app/src/main/res/values/themes.xml`
- Create: `app/src/main/res/values-night/themes.xml`

- [ ] **Step 4.1: Change values/themes.xml to DayNight**

Current:
```xml
<style name="Theme.EzWorkSafe" parent="android:Theme.Material.Light.NoActionBar">
```

After:
```xml
<style name="Theme.EzWorkSafe" parent="android:Theme.Material.DayNight.NoActionBar">
```

- [ ] **Step 4.2: Create values-night/themes.xml**

```bash
mkdir -p app/src/main/res/values-night
```

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <style name="Theme.EzWorkSafe" parent="android:Theme.Material.DayNight.NoActionBar">
        <item name="android:statusBarColor">@color/background</item>
    </style>
</resources>
```

Note: The `background` color resource is `#FFF5F5F5` (light gray). For dark mode, we may want a darker status bar. If the dynamic theme handles it, this file still overrides the status bar color. Since we're using Material You (which creates its own status bar coloring), we could also just let the theme default handle it. But keeping this file ensures the status bar color is explicitly set.
